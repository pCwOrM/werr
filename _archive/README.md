# 🏛️ Historical Ecosystem & Site Archives

This directory permanently preserves preceding versions, baseline test previews, and historical interactive demonstrators for scientific and audit integrity.

> **Crucial Deployment Notice:**  
> These archives are permanently preserved in the Git repository but are **strictly excluded from online public deployment on GitHub Pages (`werr.io`)**. The automated deployment pipeline (`.github/workflows/pages.yml`) prunes `_archive` prior to artifact upload, ensuring that outdated baselines, test duplicates, and legacy pages do not linger as active web endpoints.
